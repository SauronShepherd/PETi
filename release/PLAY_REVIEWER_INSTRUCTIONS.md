# Play Reviewer Instructions

Status: `TEMPLATE_EXTERNAL_TEST_ACCOUNT_REQUIRED`

1. Sign in with the reviewer test account supplied through Play Console.
2. Create a dog profile and confirm that owner-scoped data is visible only to
   that account.
3. Import a photo/document through the system picker; no broad media access is
   required.
4. Run PETi Check and inspect visible observations, uncertainty, limitations,
   source provenance and safety guidance. The product must not be read as a
   diagnosis or prescription.
5. Open Timeline, Measurements, Records, Care and Weekly Reports.
6. If enabled for the track, exercise the rewarded-ad flow and confirm that a
   reward is granted only after server verification.
7. Verify unsupported modality/capability requests fail closed.
8. Use the account-deletion action and verify the account is no longer usable.

The reviewer must not use production customer data. Credentials, project
URLs, Play product IDs and external evidence are supplied separately and are
never committed to this repository.
