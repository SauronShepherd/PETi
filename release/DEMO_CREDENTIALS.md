# Demo access procedure

No credentials are committed to this repository. For a judge demo, the team
must provision a disposable Firebase Auth account in the sandbox project,
record only its expiration and owner, and deliver the credential through the
submission platform's private reviewer channel. Use synthetic pet evidence and
delete the account and all fixture data after the demo.

The public demo must never contain service-account keys, Gemini keys, Firebase
ID tokens, signed media URLs, real owner identities, or real pet-health data.
