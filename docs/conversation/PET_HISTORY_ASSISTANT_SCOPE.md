# PETi History Assistant Scope

The assistant answers bounded questions about authorized PETi history only. It retrieves structured sources before any optional narration, cites material claims, preserves contradictions, and returns insufficient evidence when no source exists. It does not diagnose, prescribe, infer disease, browse the web, or turn conversation into canonical pet facts. Conversation messages are private conversational data, not a source of truth, and are deletable independently of pet records.
