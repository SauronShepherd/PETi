# PETi privacy principles

PETi stores account, pet-profile, care, measurement, veterinary-record, and
analysis metadata only for authenticated owner-scoped use. Private media is
stored through authorized cloud access and is not exposed through permanent
public URLs. AI receives only the selected source media and required context.

Users can export account data and request account deletion through the
authenticated privacy surface. Deletion handles dependent source-backed facts
explicitly. Ordinary viewing, reviewing, searching, reporting, and deletion do
not require advertising or premium access.
