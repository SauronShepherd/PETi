# PETi Portable Package v1

Portable packages are owner-authorized, pet-scoped JSON manifests. They contain canonical PETi entities, provenance, source references and attachment metadata. Billing, internal secrets, provider transcripts and hidden operational data are never exported. Raw media is opt-in, size-previewed, private and separately expired. Imports are schema-validated previews requiring explicit confirmation; duplicates are preserved and linked rather than silently merged.
