# Phase 1

Phase 1 adds the first secure product domain: deterministic/local authentication boundaries, canonical PETi users, server-authoritative roles, backend species registry, generic AnimalProfile pet CRUD, owner isolation, soft deletion, and idempotent creation. Android uses auth and repository interfaces; Firestore remains backend-only.

Out of scope: AI, media, credits, ads, billing, care, timeline, records, and reports.
