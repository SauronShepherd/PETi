# Demo runbook

1. Start the documented backend and web client with sandbox configuration.
2. Open the authenticated judge surface and select one owned dog.
3. Submit a fresh stool image and request a comparison plus a useful reminder.
4. Follow the persisted run status and step list; refresh once to demonstrate
   resume from server state.
5. Inspect the provenance section and the proposed reminder.
6. Approve the exact proposal, then show the canonical reminder and ActionReceipt.
7. Use `/?demo=1` only to show the synthetic preview; leave its preview banner
   visible and do not present it as a real run.

If cloud credentials or deployment evidence are unavailable, say so explicitly;
do not substitute the synthetic preview for proof of the real path.
