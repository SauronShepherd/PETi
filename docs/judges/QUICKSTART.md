# PETi quickstart

The repository's deterministic judge surface is the web client under `web/`.
Run the documented local checks from the repository root, then open `/?demo=1`
for the explicitly synthetic preview. The authenticated agent workflow uses
`POST /v1/dogs/{dog_id}/agent-runs` and requires the configured backend and
credentials; the preview never creates a backend run.

See [START_HERE.md](START_HERE.md), [DEMO_RUNBOOK.md](DEMO_RUNBOOK.md), and
[TESTING_AND_VERIFICATION.md](TESTING_AND_VERIFICATION.md).
