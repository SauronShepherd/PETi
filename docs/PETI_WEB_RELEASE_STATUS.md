# PETi Web Release Status

PETi is a web-only application. The active client is the responsive browser
application under `web/`, backed by Firebase, Google Cloud, Gemini/Vertex AI,
Cloud Run, Cloud Tasks, Firestore and Cloud Storage.

The release gate covers the web client, backend, cloud infrastructure,
security, multi-agent execution, responsive UI evidence and public hosting.
Local web and backend verification must pass before external certification.
