# PETi Hackathon Demo Script (four minutes maximum)

Language: English or English-subtitled recording. Use synthetic, non-sensitive
pet evidence only.

| Time | Demonstration |
| --- | --- |
| 0:00–0:25 | State the owner problem: an ambiguous concern needs organized evidence, not a diagnosis. |
| 0:25–0:50 | Submit a synthetic multimodal case from Android and show the bounded goal/run. |
| 0:50–2:40 | Show evidence intake, PETi Check, specialist handoff, private Cloud Tasks/Cloud Run, Gemini result, Firestore provenance, and the safety review state. |
| 2:40–3:25 | Show the architecture and explain owner-scoped tools, durable state, retries, and kill-switches. |
| 3:25–3:50 | Demonstrate insufficient evidence or a blocked claim becoming `REVIEW_REQUIRED`. |
| 3:50–4:00 | Close with the Taskmaster value: useful continuity without diagnosis, prescription, or false certainty. |

Do not show tokens, signed URLs, personal data, customer payloads, billing, or
features outside phases 00–17.
