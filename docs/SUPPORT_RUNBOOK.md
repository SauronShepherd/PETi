# PETi support runbook

Use the authenticated support code endpoint to create a privacy-safe support
reference. Support cases must use the generated code and correlation ID; do
not copy raw document bodies, extraction text, media URLs, or clinical content
into general support logs.

Operational metrics and feature flags are restricted to administrative
identities. Emergency cost controls disable variable-cost operations without
removing access to existing results, records, safety guidance, privacy, or
deletion.
